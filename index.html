Claude Code Harbor

Every Claude Code session docks as a ship. Every tool call is a container the crane loads. Subagents head out as tugboats. When a session needs you, the lighthouse turns on.

  1. Paste this prompt into Claude Code. It installs one small hook script and gives you your private link.
  2. Open the link. Restart your Claude Code sessions and watch them dock.

  

  
Runs on Claude Code hooks, so it uses zero tokens. The hook sends only the event name, a short session id, the project folder name and the tool name to your private ntfy.sh channel. It never sends prompts, code, commands or file contents.
